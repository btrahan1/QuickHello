# QuickHello 🚀
**QuickHello** is a premium, mobile-first communication dashboard designed for the ultimate "Quick Message" experience. Whether you're letting a partner know you're heading home or sending a quick ☕ to a coworker, QuickHello makes it a one-tap affair.

## 🖱️ Quick Interaction Guide
- **Single Tap**: Instantly send a message or switch a contact.
- **Long Click (800ms)**: Opens a sleek contextual menu to **Edit** icon data (Name, Emoji, Message) or **Delete** custom entries.
- **Tap Outside**: Dismiss any open menu by tapping anywhere else.

## ✨ Features

### 👥 Multi-Contact Dashboard
- **Horizontal Contact Bar**: Save multiple "Quick Contacts" and switch between them with a single tap.
- **Contact Picker Integration**: Seamlessly import names, numbers, and even profile pictures using the modern Web Contacts API.
- **Visual Identities**: Each contact has their own avatar, making it easy to identify your recipient at a glance.

### 🍱 Customizable Action Grid
- **Dynamic Buttons**: Add your own custom message buttons with any emoji, label, and text you want.
- **Universal Editing**: Every button on your dashboard is editable. Don't like the default "Coffee" message? Just override it!
- **Contextual Menu**: A familiar mobile experience—Long-press any icon to open a sleek, glassmorphism menu for Editing or Deleting.

### 💎 Premium Design & UX
- **Glassmorphism UI**: A stunning dark-mode aesthetic with blurred backgrounds, vibrant gradients, and smooth animations.
- **High-Compatibility Gestures**: Robust touch handling ensures that a long-press for editing never accidentally triggers an SMS.
- **Smooth Autoscroll**: The app intelligently scrolls to the edit controls when you open them, keeping your workflow fluid.

### 🛡️ Safety & Reliability
- **Local Persistence**: All your contacts and custom buttons are saved securely in your browser's local storage.
- **Reset Safety Valve**: Made too many changes? Use the **Reset Defaults** button at the bottom to restore the original experience in one click.
- **PWA Ready**: Install QuickHello to your home screen for a full-screen, app-like experience without the browser chrome.
