# QuickHello

A simple, premium web app to send quick SMS messages to a pre-configured contact.

## Features
- Save a contact name and number locally (Local Storage).
- One-tap buttons for common messages (Coffee, Wave, Heart).
- Clean, modern UI with dark mode support and glassmorphism.
- Uses the modern Contact Picker API (where supported) for easy configuration.

## Deployment
This app is designed to be hosted on GitHub Pages.

1. Push to GitHub.
2. Go to Settings > Pages.
3. Select the `main` branch as the source.
